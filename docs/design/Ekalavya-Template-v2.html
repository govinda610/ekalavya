Recursion, illustrated

पुनरावृत्ति · the return upon itself

A recursive function trusts a smaller copy of itself to solve the smaller problem, then combines. Every recursion needs two things: a base case that stops the descent, and a step that moves toward it.

In tree traversal, the order you visit the parent decides everything. In post-order you defer the parent until both children are done — which is how you free a subtree or compute its size bottom-up.

Ask about this ✦
"You are not writing a loop that repeats. You are writing a promise that trusts a smaller you." — the stone guru
