Why not the AI triad

Mint/cyan/violet neon reads "SaaS dashboard." We anchor in indigo night + carved stone and let a single precious metal — gold — carry status. Nothing glows unless it was earned.

Lighting, not ambient glow

Drama comes from directional light and deep shadow (God-of-War menu craft), applied surgically to hero moments — a level-up bloom, an arrow strike — not smeared across every card.

Meaning in colour

Gold = mastery/earned. Vermilion/sindoor = danger, loss, the sacrificed thumb. Peacock teal = unlocked, live, information. Each hue is a semantic, never decoration.

Texture is the theme

Film grain + carved-stone insets + gold hairline yantra frames give every surface a hand-made, temple-relief quality. This is a place, not a control panel.
